It omits drawings/annotations/organisation. Snapshots are bounded at 10,000 entities, cursor coverage is inherited from the original snapshot, complete transaction groups stay together and current access is rechecked. Do not silently upgrade an old cursor's coverage or interpret a filtered/empty result as deletion.
- The [drawing specification](CANONICAL-DRAWING-IMPLEMENTATION-SPEC.md) preserves one native drawing UUID per selected sheet, immutable original/page/version geometry, explicit pin history and private ownership. Existing token-scoped `synced_drawings` and uploaded report JSON are publication snapshots, not canonical project masters. A compatible rollback must also respect new coverage/purpose/permission constraints. Startup success alone does not prove safe rollback. See [BACKEND-GRAPH-IMPLEMENTATION.md](BACKEND-GRAPH-IMPLEMENTATION.md).
